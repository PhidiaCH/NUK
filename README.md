# NUK

## ASE Low-Carbon Packaging & TEG Expert Solver

This repository contains a Streamlit prototype for an ASE low-carbon packaging and thermoelectric generator (TEG) decision system. The app includes a dedicated `APP 功能視窗` tab that summarizes current design status, guides the recommended workflow, and exports the active design parameters as JSON.

### UI preview

Open `ui_preview.html` in a browser to view a static mockup of the Streamlit interface without installing Python dependencies.

### Run locally

```bash
pip install -r requirements.txt
streamlit run app_teg.py
```
