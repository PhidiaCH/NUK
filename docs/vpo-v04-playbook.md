# VPO 智慧幕僚系統 V0.4 落地 Playbook

## 1. 為什麼 V0.3 會難用

常見失敗原因如下：

- 使用者需要自己想 prompt，導致每次品質不穩。
- 系統輸出像顧問報告，但不能直接貼回工作場景。
- 沒有要求 owner、deadline、status，所以整理完仍然不能推進。
- 缺少固定節奏，大家想起來才用，無法形成習慣。
- 場景太大，想同時處理知識管理、專案管理、策略分析與自動化。

V0.4 的核心修正是：把 VPO 變成「固定節奏中的固定幕僚動作」。

## 2. 30 天導入計畫

### 第 1 週：只做會議轉行動

目標：讓使用者感覺「會議後不用再手動整理」。

做法：

1. 選 2 個真實會議作為試點。
2. 會後貼上逐字稿或會議筆記。
3. VPO 只輸出四段：決議、待辦、風險、需升級事項。
4. 專案負責人確認 owner 與 deadline。
5. 直接貼回團隊既有工具。

成功標準：會議後 10 分鐘內完成可發布紀錄。

### 第 2 週：加入每日站會整理

目標：讓 VPO 變成每天早上的狀態雷達。

做法：

1. 每人用三行回報：昨日完成、今日計畫、阻礙。
2. VPO 彙整成團隊狀態。
3. 只標出需要主管介入的阻塞。
4. 不要求完整專案管理，只要求提早看到問題。

成功標準：主管每天 5 分鐘內知道哪裡卡住。

### 第 3 週：加入風險雷達

目標：把模糊的不安變成可管理的風險。

做法：

1. 每週輸入目前進度、外部依賴、延遲項目。
2. VPO 依影響與發生機率排序。
3. 每個風險都要有應對方案、owner、升級條件。
4. 只追蹤前 5 大風險，避免列表失控。

成功標準：重大風險至少提前一週被看見。

### 第 4 週：固定週報

目標：讓向上管理變得穩定。

做法：

1. 收斂本週完成、下週計畫、阻礙、需決策事項。
2. VPO 產出主管版週報。
3. 專案負責人只調整語氣與敏感資訊。
4. 週報格式固定，不每週重做。

成功標準：週報製作時間低於 20 分鐘。

## 3. 標準輸入模板

### 會議轉行動

```text
請用 VPO 會議轉行動格式整理以下內容。

會議目的：
與會者：
原始紀錄：

請輸出：
1. 本次決議
2. 待辦事項：task / owner / deadline / status
3. 風險與阻礙：risk / impact / mitigation / owner
4. 需要升級或主管決策的事項
5. 會後可直接貼出的訊息版本
```

### 每日站會整理

```text
請用 VPO 每日站會格式整理以下回報。

團隊成員回報：
- 姓名：昨日完成 / 今日計畫 / 阻礙

請輸出：
1. 團隊整體狀態：綠 / 黃 / 紅
2. 今日重點
3. 阻塞清單：blocker / owner / needed support
4. 需要主管介入的事項
5. 可貼到團隊頻道的摘要
```

### 風險雷達

```text
請用 VPO 風險雷達格式分析以下專案狀態。

專案目標：
目前進度：
已知問題：
外部依賴：
期限限制：

請輸出：
1. 前 5 大風險
2. 每個風險的 impact / probability / owner
3. 緩解方案
4. 何時需要升級
5. 本週最重要的 3 個行動
```

## 4. 標準輸出規格

VPO 的輸出必須符合以下規格：

- **短摘要**：3 行內說明目前狀態。
- **行動表**：每列都要有 task、owner、deadline、status。
- **風險表**：每列都要有 risk、impact、mitigation、owner。
- **升級事項**：只列需要主管或跨部門決策的事項。
- **可貼出版本**：最後附上一段可直接貼到溝通工具的文字。

## 5. 不該做的事

- 不要求團隊更換既有工具。
- 不讓 VPO 一次處理所有管理問題。
- 不產出沒有 owner 的建議。
- 不產出不能被複製貼上的長篇分析。
- 不把 AI 建議當成最終決策。

## 6. 衡量指標

| 指標 | 目標 |
| --- | --- |
| 會議紀錄完成時間 | 10 分鐘內 |
| 週報製作時間 | 20 分鐘內 |
| 待辦事項 owner 完整率 | 95% 以上 |
| 待辦事項 deadline 完整率 | 90% 以上 |
| 使用者每週使用次數 | 至少 3 次 |
| 重大風險提前揭露 | 至少提前 1 週 |

## 7. 下一版可以再做什麼

等 V0.4 的固定工作流穩定後，才建議進入 V0.5：

1. 串接 Notion、Jira、Slack 或 LINE。
2. 建立專案記憶與決策紀錄庫。
3. 自動追蹤 action item 是否逾期。
4. 針對不同角色提供不同輸出版：主管版、PM 版、工程版。
5. 加入權限、敏感資訊遮罩與稽核紀錄。
